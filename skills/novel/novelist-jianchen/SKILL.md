```
### AI套句黑名单（命中即重写）

```

### 应用规则

1. **行为约束优先级 = 技法约束同级**：风格约束与 ANTI_XXX 约束同等强制力
2. **锚点是密度参考**：看锚点判断"应该有多厚"的战斗描写，禁止复制句式
3. **quirk 适度植入**：全场景 1-2 处即可，过多会显得刻意
4. **黑名单零容忍**：命中任一黑名单词组的句子必须重写，不能只删词

### 代价词汇层（v1 精细化参考）

**Collection**：`power_cost_v1`（战斗代价描写）+ `power_vocabulary_v1`（力量词汇）

```python
from modules.knowledge_base.hybrid_search_manager import HybridSearchManager
search = HybridSearchManager()

# 力量代价参考（从 5897 本小说提炼的真实战斗代价写法）
power_cost_refs = search.search_power_cost(
    query=f"[力量体系名]战斗代价 {scene_brief}",
    top_k=3
)
# 返回字段: text(代价描写段落), power_type(力量体系), cost_category(代价类型), scene_context

# 力量词汇参考
power_vocab = search.search_power_vocabulary(
    query=f"[力量体系名] 招式词汇",
    top_k=5
)
# 返回字段: text(词汇上下文), power_type, category
```

**如何使用结果**：
- `power_cost_refs` → 提取 `text` 字段作为"代价写法参考"注入 Phase 2 prompt 头部
- 格式：`【代价写法参考】\n{ref1.text}\n---\n{ref2.text}`
- `power_vocab` → 提取同体系的招式词汇，融入战斗动作描写
- **无结果时**：跳过，不影响主流程

## 核心方法论

### 战斗节奏标准

| 阶段 | 字数占比 | 功能 | 情绪曲线 |
|------|----------|------|----------|
| **铺垫** | 约40% | 蓄势、拉仇恨 | 30%→70% |
| **爆发** | 约45% | 释放、反转、爽点 | 70%→100%→释放 |
| **沉淀** | 约15% | 余波、影响、伏笔 | 回落至20% |

### 铺垫五要素（至少完成3个）

| 要素 | 内容 |
|------|------|
| **实力对比反差** | 对手明面碾压 + 主角隐藏底牌 |
| **围观者态度** | 亲友劝阻/敌人嘲讽/中立者开盘口 |
| **环境气氛渲染** | 天气异常/场地异象/器物反应 |
| **仇恨值拉满** | 触碰逆鳞/当众羞辱/利益冲突 |
| **赌注/后果** | 大人物对赌/失败代价明确 |

### 爆发六大爽点特征

| 特征 | 写法 |
|------|------|
| **词汇夸张化** | "摧枯拉朽"、"遮天蔽日" |
| **环境破坏** | 空间开裂、建筑崩塌 |
| **旁观者反应** | 从嘲讽→震惊→倒吸凉气 |
| **招式具象化** | 用比喻让招式可视化 |
| **节奏加快** | 短句密集、平均句长8-15字 |
| **五感齐用** | 视觉+听觉+嗅觉+触觉 |

## 能力代价描写标准

### 代价判断三条红线

| 标准 | 说明 |
|------|------|
| **资源稀缺性** | 消耗有限资源（体力、寿命、材料） |
| **后果不可逆性** | 产生无法完全恢复的损伤 |
| **选择权衡性** | 需要"思考值不值得" |

### 代价类型体系

| 类型 | 具体表现 |
|------|----------|
| **身体代价** | 肌肉撕裂、器官损伤、寿命缩减 |
| **精神代价** | 记忆丧失、人格分裂、情感钝化 |
| **社会代价** | 身份暴露、关系破裂、名誉牺牲 |
| **资源代价** | 金钱消耗、材料稀缺、机会成本 |
| **等价交换** | 以命换命、以伤换伤、因果循环 |

### 弱者战胜强者五条件

| 条件 | 合理做法 |
|------|----------|
| **信息不对称** | 提前研究弱点 |
| **代价不对等** | 弱者敢拼命 |
| **环境利用** | 陷阱、天气、地形 |
| **能力克制** | 提前设定克制关系 |
| **惨胜代价** | 断臂、暴露身份、寿命缩减 |

## 禁止项

| 禁止 | 表现 |
|------|------|
| **无代价胜利** | 瞬满血复活、无限蓝条 |
| **代价可逆** | 假牺牲、睡一觉恢复寿命 |
| **代价转移** | 队友买单、反派买单 |
| **代价不对等** | 流一滴血换灭世一击 |
| **代价遗忘** | 第三章断臂、第三十章手臂还在 |
