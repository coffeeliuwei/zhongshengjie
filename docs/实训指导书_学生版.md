# 准备工作（一次性）

> **做什么：** 在电脑上安装 4 个工具，和 AI 对话写作的基础环境。
> **预计时间：** 15 分钟
> **做几次：** 只做一次

---

## 第1步：安装 4 个工具

按顺序检查，没有的按提示安装。

**① Python 3.12**

打开 PowerShell（按 `Win+S` 搜索"PowerShell"），输入：
```
python --version
```
- 看到 `Python 3.12.x` → ✅ 已有，跳过
- 看到其他版本号或报错 → 去 [python.org/downloads](https://www.python.org/downloads/) 下载 3.12，安装时**勾选"Add python.exe to PATH"**，装完重开 PowerShell

**② Git**
```
git --version
```
- 看到任意版本号 → ✅ 已有，跳过
- 报错 → 去 [git-scm.com](https://git-scm.com/download/win) 下载安装，一路 Next

**③ Docker Desktop**
```
docker --version
docker ps
```
- 两条都有输出 → ✅ 已有，跳过
- 未安装 → 去 [docker.com](https://www.docker.com/products/docker-desktop/) 下载安装，安装后重启电脑，右下角出现鲸鱼图标才算启动成功
- `docker ps` 报错（docker 有但不能用）→ 双击桌面 Docker Desktop 图标等鲸鱼变绿

**④ 安装 Claude Code 插件**

PowerShell 里执行（整行完整复制，不要换行）：

```
New-Item -ItemType Directory -Force "$env:USERPROFILE\.config\opencode" | Out-Null; Set-Content "$env:USERPROFILE\.config\opencode\opencode.json" '{"plugin":["superpowers@git+https://github.com/obra/superpowers.git","oh-my-openagent"]}'
```

看到光标回到下一行（没报错）→ 成功。**重启 opencode**（关掉再重新打开）让插件生效。

**笔记本独显（防过热，分两步跑）：**
```powershell
# 第一步：场景案例库（把手机/散热垫放好，笔记本别放被子上）
python -u tools/case_builder.py --all --embed-batch 64 2>&1 | Tee-Object logs\case_log.txt
# 第一步跑完后，第二步：
python tools/build_all.py --only extract,technique_batch,dialogue
```

**仅CPU模式（建议先跑1000本，后续再补）：**
```powershell
python -u tools/case_builder.py --all --embed-batch 16 --limit 1000 2>&1 | Tee-Object logs\case_log.txt
# 跑完后：
python tools/build_all.py --only extract,technique_batch,dialogue
```

# 遇到问题怎么办

> **万能做法：** 把你看到的报错内容**完整复制**，粘贴给 opencode 或 Claude Code，说"我在做XX的时候看到这个报错"，它会帮你解决。不需要自己看懂英文。

---

**Q：Docker Desktop 显示 "WSL needs updating"**

管理员身份打开 PowerShell，执行：
```powershell
wsl --update
```
完成后回 Docker Desktop 点 **Try Again**。

---

**Q：Qdrant 没有启动**

在 Claude Code 里说：
```
帮我检查 Qdrant 容器状态并重新启动
```

---

**Q：AI 说"找不到世界观配置"**

```
帮我检查当前小说"[你的小说名]"的世界观配置是否正常
```

如果丢失，重新描述世界观，通过对话重建即可，不影响已有章节。

---

**Q：AI 语言模型下载太慢或失败**

在 opencode 里说：
```
BGE-M3 模型下载失败，帮我用备用镜像重试
```

或找老师要离线模型文件，解压后告诉 Claude Code 路径，它会帮你写入配置。

---

**Q：AI 生成内容感觉很普通**

初期正常，系统还不了解你的品味：
1. 直接说："这个太普通了，换个思路"
2. 用 `novel-inspiration-ingest` 录入你欣赏的写法
3. 积累 3–5 章后会明显改善

---

**Q：导入小说库时电脑自动重启**

笔记本 GPU 长时间满载会过热触发保护，属正常现象。重启后重新执行同一命令，已处理的自动跳过。

下次用更小的参数防止过热：在 opencode 里说：
```
帮我用更小的 embed-batch 参数重新运行 case_builder，我的电脑之前过热重启了
```

---

**Q：导入命令里显示"使用 CPU 推理"，GPU 没工作**

必须在 **PowerShell**（窗口左上角有 `PS C:\>` 前缀）里运行，不能用 CMD（黑色窗口）。

---

**Q：我想写另一本小说**

```
使用 novel-workflow，切换到我的另一本小说"星海纪元"
```

如果"星海纪元"还没有建立，系统会引导你创建。

# 附录：config.json 配置说明

> **通常不需要手动修改**——安装时 AI 会自动帮你配好。只有出问题或需要调整时才看这里。

打开 `config.json`（用记事本即可），只需要关注以下几项：

---

### ① 小说名（必须和你告诉系统的名字完全一致）

```json
"worldview": {
    "current_world": "天道余烬"
```

---

### ② 境界体系（从低到高）

```json
"validation": {
    "realm_order": ["觉醒期", "凝气期", "通脉期", "融道期", "天道期"]
```

如果你的小说没有境界体系：`"realm_order": []`

---

### ③ 离线模型路径（只有老师给了离线模型时才改）

```json
"model": {
    "model_path": "D:/models/bge-m3"
```

注意路径用正斜杠 `/`，不用反斜杠。

---

### ④ 路径配置（安装时已自动填好，一般不用动）

```json
"paths": {
    "skills_base_path": "C:/Users/你的用户名/.agents/skills",
    "cache_dir":        "E:/众生界_cache",
    "temp_dir":         "E:/众生界_temp",
    "mobi_temp_dir":    "E:/tmp_mobi"
},
"novel_sources": {
    "directories": ["E:\\小说资源"]
},
"extractor": {
    "output_dir": "E:/novel_extracted"
}
```

所有 `E:/` 是你的数据盘，安装时已经填好了。`你的用户名` 用 PowerShell 执行 `$env:USERNAME` 查看。

**各目录需要的磁盘空间：**

| 目录 | 用途 | 建议预留 |
|------|------|---------|
| `mobi_temp_dir` | mobi 格式解压临时文件 | 5 GB（不能放 C 盘）|
| `extractor.output_dir` | 提炼输出 | 80 GB |
| Qdrant 存储 | 向量数据库 | 50 GB |
| `cache_dir` | 系统缓存 | 10 GB |
